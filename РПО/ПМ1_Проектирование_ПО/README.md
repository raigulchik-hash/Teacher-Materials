# ПМ 1 — Учебные материалы

Данный раздел содержит учебные материалы профессионального модуля **ПМ 1**
по специальности **06130100 «Программное обеспечение (по видам)»**.

Материалы распределены по **результатам обучения (РО)** в соответствии
с рабочей учебной программой.

---

## 📌 Общая информация

- **Профессиональный модуль:** ПМ 1
- **Специальность:** 06130100 «Программное обеспечение (по видам)»
- **Объём модуля:** 288 часов
- **Количество кредитов:** 12

В рамках модуля изучаются вопросы проектирования программного обеспечения,
разработки технической документации, выбора методов разработки,
проектирования интерфейсов, работы с операционными системами,
программирования и компьютерных сетей.

---

# 📚 Результаты обучения

- **РО 1.1.** Постановка цели, задач и требований к программному обеспечению
- **РО 1.2.** Разработка технических спецификаций на программные компоненты
- **РО 1.3.** Методы и стратегии разработки программного обеспечения
- **РО 1.4.** Выбор программных средств для подготовки макетов модулей ПО
- **РО 1.5.** Работа с операционными системами и пакетами прикладных программ
- **РО 1.6.** Реализация численных алгоритмов средствами программирования
- **РО 1.7.** Управление и администрирование компьютерными сетями
