# РПО — Разработчик программного обеспечения

В данном разделе размещены учебные материалы для студентов специальности **«Разработчик программного обеспечения»**.

Материалы предназначены для изучения теоретических тем, выполнения практических и лабораторных работ, подготовки к текущему и итоговому контролю.

## Содержание раздела

Здесь могут размещаться материалы по следующим направлениям:

- проектирование программного обеспечения;
- программирование;
- разработка веб-приложений;
- разработка мобильных приложений;
- базы данных;
- тестирование программного обеспечения;
- работа с Git и GitHub;
- современные технологии разработки;
- практические и лабораторные работы;
- тесты и контрольные задания;
- дополнительные учебные материалы.
